# Minecraft BLOCK Total Supply API

This is a simple Express.js API to return the total supply of the Minecraft BLOCK token on Solana.

## 🧾 Endpoint

**GET /**  
Returns:
```json
{
  "total_supply": 123456789
}
```

## 🛠️ Setup Instructions

1. Install dependencies:
```
npm install
```

2. Run the server:
```
npm start
```

3. Visit in browser:
```
http://localhost:3000
```

## 🌐 Deploy to Render

- Build Command: `npm install`
- Start Command: `npm start`
- Environment: Node

Your API will be live and return total supply in JSON.
